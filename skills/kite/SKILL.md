For desktop work, read `kite docs desktop` once; for other Kite tasks start with `kite docs`. These commands work without a running node. Use only the topics needed for the task.

Use CLI commands or standard MCP tools available in your harness. Keep document revisions only while their bodies remain in context; pass `--known TOPIC=REV` to avoid rereading unchanged bodies. After compaction, fetch a missing body again.

Desktop actions affect the configured host. Inspect its status and screenshot before input. A returned PNG path needs an image viewer; it is not visual evidence by itself.
