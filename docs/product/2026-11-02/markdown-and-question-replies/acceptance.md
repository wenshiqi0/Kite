# Compact inline code and paired submitted answers

The reported Android screenshot shows inline code backgrounds filling expanded line boxes, with adjacent wrapped list lines touching. Markwon's default inline `CodeSpan` paints `bgColor` through the whole native text line. `MarkdownTextView` now draws rounded backgrounds from the inline font's ascent/descent, clipped to each native line; inline monospace uses 90% of the surrounding text size. Native selection geometry retains wrapping, list indentation, bidi runs and linked code. Table cells retain their own renderer's background and fenced code styling is unchanged.

Submitted Codex question replies now retain question IDs, full prompts and answers through Rust history, cache serialization and UniFFI. Both correlated async user envelopes and blocking tool answers project into the same explicit records. Ordinary user text is never guessed to be a reply. Successful submissions stage the paired record immediately; history synchronization reconciles the local record. Secret values are masked in display records. Android renders each pair as a joined card with a gray question panel above a blue answer panel; multi-question submissions retain separate pairs.

Validation: Rust workspace tests and all-target Clippy pass. Android Release JVM tests, debug instrumentation source compilation and Release lint pass using the matching host library to generate UniFFI metadata. Added native assertions cover compact, nonoverlapping code backgrounds across 240/320/400 dp columns and 1/1.3/2 text scales, linked code, long paths and bidi text, plus question/answer order and actual panel colors. Runtime screenshots and final public artifact verification are recorded after delivery; compilation alone is not device acceptance.
