# Kite 0.2.0-alpha.15

- Shrink the fullscreen mouse body from 128×144 to 104×112 dp and the arrow from 28 to 20 dp high, while retaining independent buttons, dragging and source-coordinate targeting.
- Tap the upper/lower wheel halves to scroll one notch, or drag for continuous scrolling. Add press highlighting, direction feedback, tactile presses and rate-limited scroll detents. Cancelling a gesture does not scroll.
- Simplify host cards to a name, connection status and Connect/Enter/Retry action. Open editing through the separate menu; move clipboard, public-key and diagnostic controls into Connection settings. Connection errors start collapsed.
- Retain saved profiles, complete history, device identity, trust and pairing. Unconnected profiles remain labelled unconnected; connected and failed states reflect the actual connection result.

This is an ARM64 Alpha prerelease using the existing signing identity. Install over the previous Alpha without clearing app data. Haptic dispatch is tested on Android; physical vibration strength depends on the phone.
