# Kite 0.2.0-alpha.13

- Rebuild history around complete synchronized data and local virtual rendering. Scrolling no longer starts network pagination or evicts old records. Old inline caches migrate to independent conversation files while hosts, device identity, trust and pairing are retained.
- Move conversation bodies out of video/status snapshots. Versioned message edits update affected rows, preserve tool-group keys and avoid replacing long lists on telemetry updates.
- Remove the 300-message / 256KiB conversation crop and the 16KiB text truncation. Preserve repeated text with distinct IDs. Background synchronization fills missing ranges, compresses transfer batches and keeps saved content on failure.
- Render visible messages with one screen of forward buffer and half a screen behind. Long tool output uses virtual text chunks.
- Restore mouse-shaped fullscreen controls with left/right buttons, a center wheel and a lower positioning grip, plus a quiet right-hand rail. The relative trackpad is confined to split view below the desktop and above Chat.
- Apply a consistent dark palette to chat, native Markdown/code/tables, sidebars, host cards, questions, approvals, popups and system chrome. Keep direct system IME, zoom/pan and source-resolution coordinate mapping.

Android versionCode: **15**. ARM64; Android 8.0 or newer. Alpha prerelease.

Validation and scope are recorded in [the implementation plan](https://github.com/wenshiqi0/Kite/blob/main/docs/implementation-plan.md). Physical-phone responsiveness and WAN behavior remain separate from emulator validation. Claude connectivity, desktop clients and multi-machine MCP remain later stages.
