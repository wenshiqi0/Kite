# Kite 0.2.0-alpha.16

- Keep the composer add menu focused on images, files and audio. Remove the floating/split/fullscreen desktop entries and rename its accessible label to Add attachment.
- Desktop entry and layout controls remain in the workspace header and on the desktop surface.
- Upload handling, model/effort settings, history, device identity, hosts, trust and pairing remain unchanged.

Kite does not yet provide a skill catalogue or explicit skill picker. This release does not add skill selection.

This is an ARM64 Alpha prerelease using the existing signing identity. Install over the previous Alpha without clearing app data.
