# Kite 0.2.0-alpha.2

Android now opens into the agent conversation workspace from the archived product designs.

- Claude / Codex session history, tool cards, fixed message composer and supported terminal approval choices.
- Draggable desktop window, edge docking, adjustable split view, fullscreen watching and Android system picture-in-picture.
- Explicit takeover with direct touch, relative trackpad, keyboard shortcuts, Unicode text entry and clipboard paste. Taking over keeps the agent running; pause / resume is a separate action with restart recovery.
- Source desktop resolution remains independent of phone layout; a small decoder-limited reduction is allowed to preserve interaction frame rate.
- Correct herdr pane routing for agent prompts and terminal actions.

The English README covers the product; build details and the Linux SSH / herdr / Sunshine setup guide are under docs. All three original product mockups are preserved in docs/product/2026-10-29.

Validation: Rust tests and Clippy, Android build and lint, iOS simulator compilation, and API 36 ARM64 emulator flows against real Linux services with a labelled controlled agent / desktop fixture. Fixture tests do not invoke a real model.

Limitations: ARM64 Android, Chinese interface and Linux X11 host discovery. No audio, Wayland / Windows / macOS discovery or iOS desktop player yet. Structured history needs the matching herdr agent integration. Voice input delegates to an installed Android speech service. Emulator / LAN observations do not establish physical-device or WAN performance.
