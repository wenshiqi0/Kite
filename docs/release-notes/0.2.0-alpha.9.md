# Kite 0.2.0-alpha.9

- Show nonblocking Codex questions as real chat forms with choices, custom answers and multi-question navigation. Keep an **Answer questions** entry beside the composer, including in desktop split view.
- Recover questions asked before the phone connected. Keep their control records separate from the recent chat window, so a long tool log cannot hide an older unanswered question. Ordinary new messages supersede earlier questions; correlated answers resolve only their own fields.
- Send answers into the existing turn while the agent is working, or continue the same session when its turn has finished. Preserve drafts until submission succeeds and display readable answers in chat history.
- Keep native blocking questions and execution approvals on their existing response channels. Async questions do not pause the agent or disable ordinary messages. Avoid a stale terminal status showing another input warning immediately after a successful answer.
- Preserve hosts, keys, trust, pairing and provider history. The matching host helper updates automatically with the APK; no service restart or manual reconfiguration is required.

Validation includes actual Codex choice/free-text answers, reconnect after a completed turn, retained answer drafts, an answer delivered inside the original active turn while using desktop split, and recovery of an old question beyond the 2 MiB recent-history window. See `docs/product/2026-10-30/async-input/acceptance.md` for scope. This is an Alpha prerelease.
