# Kite 0.2.0-alpha.17

- Keep the fullscreen arrow at a fixed screen offset from the mouse buttons. Zoom/pan recomputes source targeting without moving the arrow. At a control edge, continued dragging pans the local desktop so source edges remain reachable.
- Submit fullscreen input after 200ms of quiet. Continuous motion stays local; position/wheel/text coalesce while click, drag and key barriers retain their order. IME commits use the same window, avoiding a doubled delay. Cancellation immediately releases remote state.
- Introduce the persistent Linux Kite Node and native host panel. Phone chat, Herdr API, sessions/history and attachments route through Node. Existing Herdr/Sunshine services and provider owners are reused; closing the panel keeps them running.
- Bundle the matching Linux x86_64 host package and MCP stdio tools for host status/session queries. Full desktop remote-client UI, cross-machine message delivery and production herdr-core migration remain separate stages.

**Enable the matching Linux host package before updating Android.** This APK has no Python-direct fallback. Host profiles, history, device identity/trust and pairing are retained. Both packages are Alpha prereleases.
