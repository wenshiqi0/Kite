# Kite 0.2.0-alpha.68

本版保留 Alpha 67 的会话删除和 Android 自动恢复能力，并加入 Mac 主机预览。

- Mac 应用新增独立“本机服务”窗口和菜单栏入口，管理登录后运行的 Node / Herdr，并保留客户端外连能力。
- Mac 主机沿用 SSH、会话、聊天和 MCP 协议；新增 Darwin 进程身份、私有 Unix socket、附件读取和 Codex 0.166+ 新会话持久化适配。退出客户端不结束后台节点和任务。
- Android 增加 Mac Sunshine 捕获尺寸探测，使用目标实际显示器的像素尺寸；Linux X11 探测保持原路径。
- Mac 暂不声明 Linux 的 Agent 内存硬限额、进程暂停及 X11 桌面 MCP 工具，界面按实际能力展示。
- Mac 的实际 LAN SSH、已初始化 Codex 会话的回复和历史重连已验证。新后台会话冷启动仍待系统授权与进一步核验。Sunshine 首次系统授权、手机安装、实际桌面视频/输入/音频仍需分别验收；服务在线不等于媒体已通过。

Android versionCode 70。仅发布 Alpha prerelease；签名身份与既有 Alpha 保持一致。Mac Developer ID / 公证分发不包含在本发布。
