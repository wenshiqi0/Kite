# Kite 0.2.0-alpha.7

- Merge tool calls and public progress notes into one collapsed work group. Keep final replies separate; expanded logs stay within a bounded panel and retain each call's details.
- Add a persistent session list with new sessions, saved history, continuing replies, archive and restore. Archiving keeps the provider history and background task. Concurrent restores reuse one thread owner.
- Offer Codex / Claude when creating a session. Codex connects to the host; Claude can be saved as a clearly marked pending connection. This release does not claim a verified live Claude integration.
- Add model question cards with choices, free-form text and multi-question navigation. Answers are correlated to the actual model request, and pending forms recover on reconnect. Execution approvals stay separate.
- Show immediate sending feedback and animated thinking / tool / reply states. Stop the thinking animation when waiting for the user, completed, failed or disconnected.
- Retain existing hosts, device keys, trust, pairing and provider history. The matching host adapter is installed as `backend-v2.py`.

Validation includes offline tests, Android lint/unit checks, real Codex choice/free-form replies after reconnect, archive while a task runs, restoring a closed terminal and concurrent restore requests. Phone UI verification uses an ARM64 Android emulator; see `docs/product/2026-10-30/sessions/acceptance.md` for the exact scope.
