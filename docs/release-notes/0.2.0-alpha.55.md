服务端使用 Cargo + Bun 多 package monorepo，继承 Alpha 51 的归档资源释放协议：

- Codex、Claude 终端恢复、DSH ACP、Ply MCP、历史与附件、资源控制、桌面操作、剪贴板及 FCM 由 Bun/TypeScript 适配器运行。
- Linux 窗口与托盘使用原生 Rust/GTK；截图原子写入，避免验收读取未写完的 PNG。
- 修复从 agent cgroup 采样资源时的用户管理器路径回退。
- 修复 Codex 会话身份错绑后的恢复：向 Herdr 显式报告恢复来源和时序，并读回验证绑定；恢复失败时不再返回另一条会话。
- 保留现有会话引用、原始历史、主机身份和信任；安装器使用兼容热交接替换后端。

包含严格类型检查、格式和依赖边界检查、会话恢复及协议回归测试；完整构建与验证由本版本的 GitHub Actions 执行。现场安装验收另行记录。
