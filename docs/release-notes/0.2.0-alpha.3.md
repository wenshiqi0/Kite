# Kite 0.2.0-alpha.3

Includes the Android chat and desktop workspace introduced in Alpha 2, plus a publication fix for newly created GitHub release drafts. The publisher now waits briefly for draft visibility and retries only reads; three regression checks run in CI.

- Agent conversation and tool cards, UTF-8 prompts, supported terminal approvals.
- Draggable desktop, edge docking, adjustable split, fullscreen watch / takeover and Android system picture-in-picture.
- Takeover keeps the agent running; pause / resume is a separate operation with restart recovery.
- Keyboard shortcuts, Unicode remote text, clipboard paste and relative trackpad.
- Preserves the existing device key, host trust and Sunshine pairing.

Original designs and actual development captures: docs/product/2026-10-29. English product README and Linux backend setup guide: README.md and docs/backend-setup.md.

Validation includes 35 Rust tests, Clippy, Android build / lint, iOS simulator compilation and Android API 36 ARM64 emulator flows through real SSH / herdr / Sunshine using a labelled controlled agent and desktop fixture. No model or sample command is executed by fixture tests.

Limitations: ARM64 Android, Chinese interface, Linux X11 host discovery, no audio or iOS desktop player. Structured history needs the matching herdr integration. Voice uses an installed Android speech service. Physical-phone and WAN performance are not yet validated.
