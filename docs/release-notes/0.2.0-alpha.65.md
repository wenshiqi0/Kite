# Kite 0.2.0-alpha.65 — 安装包重打

针对 Alpha 64 再次报告的安装错误 `-103`，从同一功能源码重新构建并使用原证书签名，递增 versionCode 至 67，提供新的下载地址。

**请优先下载 `kite-0.2.0-alpha.65-arm64-v8a-compat-v2.apk` 覆盖安装。** 该包使用 v1/v2 签名，关闭 v3/v4，与普通包的应用内容和签名证书一致。无需卸载现有应用。

保留 Alpha 64 的功能及主机协议。本次只更新发行版本和安装包；Linux 主机无需为本次重打而重启或更新。

可信标签 CI 会检查签名证书、Android 16 验证路径、APK 对齐、应用内容一致性和发布附件校验和。实体手机的具体失败原因仍未从安装日志复现，重打包的安装结果以手机实测为准。
