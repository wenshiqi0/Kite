# Kite 0.2.0-alpha.67

- 会话列表和当前聊天菜单支持直接删除，无需先归档。确认后立即停止该会话后台及工具进程，释放资源，再移除 Kite 记录和聊天缓存。释放失败时保留记录以便重试。
- Android 断线后自动重连，采用递增等待；没有网络时等待网络恢复，切换网络或回到前台时主动检查连接。
- 前台连接服务在重连期间保持运行，并在系统重建服务后恢复已保存的连接意图。手动断开会取消重试，临时断线不再自动跳回设置。
- 自动恢复保留原会话和草稿，不重发消息、审批或桌面输入；主机指纹及认证错误仍需人工处理。

## 更新

本版包含配套 Linux 主机包；先升级主机，再安装 Android。Android 主包和 compat-v2 兼容包沿用原签名，可覆盖升级。compat-v2 与主包应用内容相同，供此前遇到 -103 安装问题的设备使用。

## 验证

PR #13、#14 均已通过 CI。组合源码通过 147 项 Rust 测试和 59 项服务端测试；自动恢复通过本机 SSH 断线、网络恢复、进程重建、取消重连及认证失败测试，Android 77 项 JVM 测试、原生测试源码编译及 lint 通过。标签 CI 重新构建并验证签名、版本、16 KiB 对齐和公开附件校验和。

真机 Doze、厂商后台限制和实际 Wi-Fi/蜂窝切换效果仍需设备验收。
