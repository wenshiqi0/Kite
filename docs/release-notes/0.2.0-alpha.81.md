# Kite 0.2.0-alpha.81

- 客户端可同时连接多台机器。切换工作区保留其他机器的 SSH、会话同步、资源和通知；每台机器独立重连，重启后恢复仍需连接的机器。
- 主机列表显示各自的连接状态和当前选中项；会话侧栏可直接切换机器、搜索会话，并查看活动/归档数量。单台断开与系统通知的断开全部分别生效。
- 会话默认按创建时间从新到旧，避免聊天更新或归档导致列表跳动。也可选择从旧到新、最近活动、标题；每台机器单独记住排序和选中会话。
- 归档或删除当前会话后按操作前顺序选择下一条，末尾选择前一条，并立即显示下一会话的已有缓存；操作其他会话保持当前选中项。
- 会话与桌面操作绑定目标主机和会话身份，切换机器后旧列表或桌面退出回调不会影响新工作区。

安装 GitHub Release 中的 Android APK；`compat-v2.apk` 与主 APK 内容相同，供需要 v1/v2 签名的安装器使用。沿用 Alpha 80 的签名与已有设备身份。
