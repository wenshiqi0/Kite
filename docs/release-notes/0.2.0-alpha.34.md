# Kite 0.2.0-alpha.34

- 有待答问题或待确认请求时，优先显示“等待你的回答 / 确认”，不再同时显示思考动画；当前会话的侧栏标记立即同步。
- “回到最新消息”显示门槛由 120 增至 240 dp，接近尾部的隐藏余量由 48 增至 96 dp。
- 修复划过较长历史回答时按钮提前消失的问题：显示后持续保留，只有真正接近列表尾部才隐藏。
- 临时布局状态不能将历史浏览误判为已经回到最新。

延续 Alpha 33 的签名兼容包：需要兼容签名时请选择 `-compat-v2.apk`，可使用原证书覆盖升级。

包含主分支已经合入的 Linux Node 热升级改进。自动测试与 Android 构建由 CI 校验；手机交互验收仍需单独确认。
