# Kite 0.2.0-alpha.6

- Redesign Watch / Operate controls as a compact mode entry and grouped desktop toolbar; move secondary shortcuts and mouse buttons into menus. Both modes keep zoom and source-pixel input mapping.
- Disable navigation-drawer swipe gestures, and replace raw agent status values with clear labels such as “等待消息”.
- Add live Codex model and reasoning-effort choices, persisted per host and conversation and passed to actual turns.
- Add Android image, file and audio picking, SSH upload progress, verification, retry/removal and attachment cards in history. Five files per message, 25 MiB each.
- Use a private, persistent Codex app-server shared by the phone and herdr TUI. Existing host history, device identity, trust and pairing are retained during a synchronized backend upgrade.
- Fix JNI thread reattachment after JNA callbacks when returning from file picking to desktop video.

Audio uses native model input only when advertised by the host catalog; otherwise it is uploaded for agent tools to read. Rich composer controls currently require Codex; Claude terminal chat remains text only. Codex app-server integration is experimental in this Alpha.

Validation: Rust tests and Clippy, Android Release lint/unit checks, host upload/WebSocket adapter tests, iOS simulator compilation, and controlled live model/attachment/video checks. See `docs/product/2026-10-30/acceptance.md` for scope and evidence.
