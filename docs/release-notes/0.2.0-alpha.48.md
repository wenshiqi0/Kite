DSH 和 Linux Ply 接入统一模型与能力展示：

- Harness 改为下拉框，只列出主机验证可用的后端。
- DSH 使用原生 ACP，恢复模型、思考强度及原生视觉输入，保存和恢复原生会话。
- DSH 运行中追加信息走原生 steering；空闲边界和其他受管 harness 的补充输入有序接收。
- Linux Ply 使用原生宿主聊天、模型、视觉、审批及取消通道。
- 模型和思考选项读取各后端真实目录，图片入口按当前模型能力显示。
- 保留已有 Codex/Claude 路径、会话历史和 Node 生命周期接口。

匹配主机提供 `harnessApi=2`，请覆盖安装本版客户端；Node 资源监控、内存预算和会话生命周期接口同时保留。

Ply 与 DSH 同时纳入现有主机资源统计、所有后代进程统计和共享内存预算。
