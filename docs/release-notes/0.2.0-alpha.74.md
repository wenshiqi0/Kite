Kite reads shared host configuration from `~/.config/kite/node.json`.

- Herdr and Sunshine service launchers read the shared file directly. Sunshine receives native command arguments, and desktop environment values come from the same source.
- Existing Sunshine settings are adopted once. An empty `machine` follows the system hostname. Existing state, pairing and credential paths are retained.
- `kite status --refresh` shows the configuration source, shared settings and runtime desktop/Sunshine probes. Unavailable capture or an endpoint mismatch produces degraded health.
- Android obtains service paths and ports from Node. The host editor contains the SSH connection fields.
- Validation covers configuration adoption, source rereads, secret filtering, the Rust workspace, and isolated service startup against real Sunshine with changed ports and failed desktop access.
