# Kite 0.2.0-alpha.14

- Expanding the fullscreen mouse now draws an explicit arrow pointer over the desktop. The grip moves that pointer as well as the mouse control.
- Left/right buttons and the wheel use the arrow's source-pixel coordinates, rather than the last canvas touch or the position of a mouse button. Holding and dragging a button moves the pointer with that button down.
- Keep arrow rendering and input aligned through zoom, pan, letterboxing, resizing and source-resolution changes. The pointer can continue moving when the floating control reaches an edge.
- Keep direct touch alongside the mouse, split-only trackpad, dark styling, complete conversation data and existing device/host/trust/pairing records. No backend or FFI migration is required.

This is an ARM64 Alpha prerelease, signed with the existing release identity. Install over the previous Alpha without clearing app data.
