# Kite 0.2.0-alpha.19

- Add a resident Linux X11 taskbar status icon, with ready, degraded, disconnected and processing badges. Tooltip and menu list Kite Node, Herdr and Sunshine states.
- Open the same management panel from the tray, close it back into the tray, or exit the status UI while keeping services and agents running.
- Refresh status every three seconds; clear old healthy indicators on a failed check. Node computes aggregate service health, shared by the panel and tray.
- Start the icon with the desktop login, preserving the user's existing autostart preferences. A desktop without a tray receives an accessible management window.
- Include ready-to-display PNG icons, with editable SVG sources retained in the repository. The UI does not require a system SVG decoder.

This delivery updates the Linux host UI; Android functionality is unchanged apart from its Alpha version. Existing phone identities, history, trust, pairing and host configuration are retained. Install the Linux host archive using `python3 install.py --enable`, then open Kite from the desktop menu. Relaunch the graphical UI after updating. Tray validation covers Xfce/X11; Wayland/GNOME integration remains pending.
