# Kite 0.2.0-alpha.78

Fresh installer rebuild following the handset's Alpha 77 `-103`, using the established Alpha 65 rebuild process.

- Rebuild and align the Release APK, then sign it again with the original certificate. Retain both the primary v1/v2/v3 and compatibility v1/v2 packages.
- Advance to versionCode 80 and a new immutable download URL. Cover-installation retains the application's existing data and identity.
- Retain Alpha 77's readable structured-report presentation and Alpha 76's parent/child session identity fix.

The application implementation is unchanged from Alpha 77. Its public compatibility APK passed SDK 37 and independent SDK 35 signature verification and an isolated Android 16 in-place upgrade; those checks did not reproduce the physical handset failure. This requested rebuild provides fresh installer bytes without attributing the phone's error to an unverified cause. The running host does not require an update for this packaging-only release.
