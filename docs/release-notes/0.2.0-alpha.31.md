# Kite 0.2.0-alpha.31

- Android 会话列表显示运行中、待回答、待处理、启动中、暂停、完成、失败及未连接状态；未打开和已归档会话也会更新状态。
- 支持 Codex 原生生成图片：会话内预览、点击放大、双指缩放、保存到系统文件，以及已下载图片的离线查看。
- 图片通过 SSH 单独下载并校验，避免大图阻塞聊天同步；支持 PNG/JPEG/WebP，单图上限 25 MiB。

请同时更新本版本 Android APK 和 Linux 主机端。

验证：112 项 Rust 测试、Clippy、27 项主机适配器测试；真实 Codex 0.164.0 生成图片、历史投影和图片取回校验通过。Android Release 构建、lint 和 JVM 测试由 CI 验证。Android 原生预览/保存的真机运行验收仍待进行。
