# Kite 0.2.0-alpha.71

- 稳定 Android 聊天页面的流式回复：生成状态切换时保留相同的富文本和选区，避免无内容变化的重复重绘。
- 自动跟随根据实际内容高度调整滚动；用户翻看历史时立即停止跟随，回到底部后继续跟随。
- 保留 Alpha 70 的功能与签名，可直接覆盖升级。本次修复只需更新 Android 客户端。

Validation: 78 Android JVM tests, Android lint and 13 Android 16 native presentation tests, including 24 individually drawn streaming updates, stable native text/view identity, paused history reading and completion. The tagged CI rebuilds and verifies the signed Release APK and synchronized host assets. Physical-handset confirmation remains pending.
