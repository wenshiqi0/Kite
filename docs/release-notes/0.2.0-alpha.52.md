服务端重构为 Cargo + Bun 多 package monorepo：

继承 Alpha 51 的归档资源释放协议，统一迁入 TypeScript；输入、恢复与回收共用 owner 租约，未归档会话不做闲置超时回收。

- Codex、Claude 终端恢复、DSH ACP、Ply MCP、历史与附件、资源控制、桌面操作、剪贴板及 FCM 迁入 TypeScript，使用 Bun 运行。
- 启用严格类型检查、Biome lint、包依赖边界检查及隔离协议测试。
- Linux 窗口与托盘改为原生 Rust/GTK，客户端界面不依赖 Python 或 Bun。
- 保留 CLI/IPC、会话引用与存储合同；匹配安装器将主机配置改为 Bun。
- 主机包包含 kite-node 和 kite-desktop 原生二进制，构建时嵌入按摘要固定的适配 bundle。

此说明为待发布版本；构建与测试记录见 docs/development/bun-server.md。真实模型、手机及生产安装验收另行记录。
