# Kite 0.2.5

- 聊天中的文本、Markdown、JSON 等文件引用改为紧凑的行内文件名，随正文自然换行，不再插入整行卡片和“点击预览”副标题。
- 文件前后的句子、列表缩进和 Markdown 样式保持连贯；点击文件名仍可打开原有预览并保存文件。
- 已有聊天记录同样应用新排版。图片相册、音视频、工具和问答仍按原有顺序展示。

验证：Android 16 模拟器的 17 项原生界面测试通过，覆盖实际点击预览、行内换行、列表、特殊字符文件名、流式文本、混合内容和图片相册；Release 构建、JVM 测试及 lint 检查通过。
