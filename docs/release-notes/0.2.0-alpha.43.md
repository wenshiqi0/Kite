# Kite 0.2.0-alpha.43

- Android 新建会话按主机验证过的可用目录展示 Codex、Claude 与 DSH。DSH 默认关闭，只有主机环境变量启用、模型服务鉴权与 SDK 握手通过后才显示。
- 新增 DSH SDK 托管会话：文本对话、公开回复、工具过程、持久历史、归档与重连。客户端初始化完成后才能发送，未接入的附件、模型设置、Skill、额度、暂停和终端入口隐藏。
- 保留现有设备身份、主机信任、配对与会话目录。匹配的 Linux 主机包新增 `harnessApi=1`；请先更新主机，再覆盖安装客户端。

源代码检查包括 140 项 Rust 测试、69 项 Android JVM 测试、40 项主机适配器测试、5 项安装/打包测试、8 项发布器测试，以及 Clippy、Android lint 和原生测试源码编译。真实 DSH 已验证两轮记忆、工具读取、同 owner 重连和原始输入不重复。原生界面与公开 APK 验证结果单独记录在 [验收说明](../product/2026-11-02/dsh/acceptance.md)。

DSH 主机变量与 SDK 会话恢复语义见[按需配置指南](../development/dsh.md)。本阶段不接管外部 DSH TUI，不将新的 SDK 进程宣称为原生 SDK 内存恢复，也不自动重放结果未知的 turn。
