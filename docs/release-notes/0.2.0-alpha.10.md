# Kite 0.2.0-alpha.10

- Explicitly include APK v1, v2 and v3 signatures using the existing Alpha certificate. Preserve package identity, device keys, saved hosts, history and pairing when upgrading.
- Require every signature scheme and 16 KiB ZIP alignment to pass before publication; record these checks in the release manifest.
- Address the reported Android 16 `-103` certificate-collection failure with a freshly built, fully signed attachment. The Alpha 9 attachment passed v2 integrity verification; its exact failure on the reported handset is not yet reproduced. Handset confirmation remains necessary.

Application behavior is unchanged from Alpha 9, including chat question forms and recovery of older pending questions. Install this APK as an update to retain existing data.
