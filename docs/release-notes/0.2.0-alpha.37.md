# Kite 0.2.0-alpha.37

- 待答问题 / 待确认请求优先显示等待提示，不再同时展示思考动画。
- “回到最新”显示门槛改为 240 dp、近尾隐藏余量改为 96 dp；修复划过长历史回答时按钮提前消失的问题。
- 修复中文句末加粗紧接后续文字时残留 `**` 的显示；原始消息内容保留。
- 发送前的草稿和历史消息附件均可点击预览：图片放大、音频播放/暂停/拖动进度、文本阅读及保存。预览音频不自动播放，关闭或离开界面会停止。
- 修复 Linux 升级检查的心跳文件读写竞态，稳定桌面中文输入节奏，并包含主分支的 Node 热升级、桌面操作和渐进文档能力。

附件预览需要同步更新本版本 Linux 主机端。继续提供同证书的 `-compat-v2.apk` 签名兼容包，可覆盖升级。自动检查与实际手机交互验收分别记录。
