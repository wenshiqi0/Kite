# Kite 0.2.0-alpha.51

- Treat resource release as a shared harness capability, implemented by managed Codex, DSH and Ply adapters.
- Add “释放后台进程” to Android’s archived session list and `kite sessions release-archived` to the host CLI. Manual and automatic cleanup share the same verified command.
- Release archived idle owners once restorable context is saved, retaining running or blocked work and all session history. Restoring recreates the owner on its original context.
- Remove the one-hour idle expiry for unarchived sessions, including rejection of stale idle-timeout release requests.
- Serialize release against input, restore and catalog changes; reclaim only the released owner’s file cache. Fix the installed adapter path used by lifecycle subprocesses.

Validation: workspace Rust tests, host lifecycle command tests, Clippy, 71 backend tests, 73 Android JVM tests, Release lint and native test-source compilation pass. DSH/Ply cold-restoration tests preserve native context and history. Device presentation tests were compiled but not executed because this host has no KVM access; physical-handset acceptance remains separate.
