# Kite 0.2.0-alpha.82

- 左侧改为跨机器统一会话列表：机器作为分类聚合会话，包含离线缓存；搜索覆盖全部机器，分类“更多”直接进入机器配置。
- 顶部搜索改为紧凑的一行，右侧“＋”新建会话。新建时明确选择目标机器与该机器可用的 harness。
- 跨机器打开会话同时绑定机器和会话，背景机器的归档、删除及排序保持目标身份。全局排序会应用到全部机器，并为新机器保留默认顺序。
- 新增已鉴权的 ACP v1 WebSocket 入口，以及 `kite acp task`、`proxy` 和 MCP `kite_remote_task`；通过已信任 SSH 与私有 token 连接，模型凭据留在执行机器。
- 任务返回真实工具进度、结果和远端会话 ID，支持取消及继续原会话；断线不重发任务。构建可校验预期源码版本和干净工作区。
- Linux ACP 网关使用 systemd 用户服务，沿用已有 agent 资源预算；同步 Mini 原有的 X11 空属性修复，避免新主机构建覆盖该修复。

网络部分实现 WebSocket profile，尚不声明 HTTP/2/SSE 或 ACP 完整历史重放；现有 Kite 历史继续走正常主机连接。构建任务目前显式指定机器，未启用自动负载调度。
