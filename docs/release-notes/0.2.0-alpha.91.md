# Kite 0.2.0-alpha.91

- 聊天记录中的 Skill 指令显示为独立的“Skill 指令”卡片，默认折叠，避免与用户消息混淆。
- 展开卡片可查看 Skill 的来源路径和 Markdown 正文；多个 Skill 可分别展开、收起。
- 保留混合消息中的普通文字和附件顺序；普通 `$name`、标签示例和不完整信封保持原样显示。
- 历史记录和缓存保留原始内容，原生客户端仅调整展示。
- 主聊天与子任务详情共用同一个消息展示组件，统一用户消息、回复、工具组、错误、Skill 卡片和全局指令加载提示。

基于 Alpha 90，保留之前的聊天稳定性及初始化提示修复。此次只需更新 Android 客户端。
