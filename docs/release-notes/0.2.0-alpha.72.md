# Kite 0.2.0-alpha.72

Codex global instructions now appear in Android Chat as a compact "已加载全局指令" notice instead of a full user-message bubble. The same presentation applies to the initial load and subsequent reloads, including existing conversation history.

The complete instructions remain in the original conversation and continue to reach the model. Ordinary user messages, repository-specific guidance, and requests following an instructions envelope retain their full display.

This release builds on Alpha 71's stable streaming chat. Update the Android client to see the change; no host update is required.

Validation: dedicated JVM regressions cover English and Chinese instructions, reloads, initial environment context, incomplete envelopes, ordinary messages, repository guidance, and mixed requests. Tagged CI builds, tests, and verifies the signed Release APK and publishes the immutable Alpha assets. Physical-phone confirmation remains separate.
