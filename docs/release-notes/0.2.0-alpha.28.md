# Kite 0.2.0-alpha.28

- Add durable agent completion, attention, question and failure notifications from the Linux host, independent of the phone's selected conversation.
- Add Android notification permission, separate channels, lockscreen privacy, a Notifications inbox and an on/off switch. Tapping navigates through saved-host verification to the correct conversation without replying or approving anything.
- Add FCM HTTP v1 sender/receiver registration, token rotation, private host credentials, bounded retries and SSH/push deduplication. Real Firebase app/sender configuration and working Google Play services are required; this release ships unconfigured and does not yet establish delivery after OS process reclamation.
- Isolate notification storage/transport failures from normal chat. Preserve source resolution/input behavior and existing history, identity, trust and pairing.
- Keep the original long-lived Android signing identity and explicit v1/v2/v3 SDK signing pass. Publish the matching Linux host package from the same source.

Validation: Rust domain/app/host tests, backend transport/fact tests, Android native compilation/lint and publisher checks. Actual notification, installation and host deployment evidence is maintained in docs/product/2026-11-01/agent-notifications/acceptance.md. Full FCM device delivery remains pending configuration.
