## Codex 速度

在模型设置中为支持的 Codex 模型选择标准、Fast 或 Ultrafast，档位以当前账号的模型目录为准。选择按会话保存，随下一轮请求生效。切换模型时会沿用仍受支持的档位，否则切回标准速度。

## 其他改进

- Android 在聊天消息中以标签显示已选 Skill，并优先用消息正文生成新会话标题。
- 新建会话支持 Google Antigravity。启用后可选择模型和思考强度、发送图片、处理工具审批和恢复会话。[主机配置](https://github.com/wenshiqi0/Kite/blob/main/docs/backend-setup.md#google-antigravity)
