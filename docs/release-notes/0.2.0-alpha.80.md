# Kite 0.2.0-alpha.80

- Kite now archives the corresponding Codex chat after its work finishes and the host releases the session. The host also synchronizes eligible sessions previously archived in Kite.
- Kite can read Codex history from the native archive. Restoring a session keeps its original Codex thread ID and conversation.
- The Android APK and Linux host package come from the same source. Update the Android client before enabling the matching host so the client can read history as soon as Codex moves it.

Android versionCode 82. This release keeps the existing signing certificate and includes both the primary and v2 compatibility APKs. A real Codex CLI smoke test in isolated storage verified native archive state, history reads with an empty Kite cache and restoration of the same thread and transcript.
