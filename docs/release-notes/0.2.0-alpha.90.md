Kite 0.2.0-alpha.90 (Alpha)

Reclaim the blank space below the Android chat title when the resource warning is hidden.

- Retain Alpha 89's initialization indicator fix and all earlier chat behavior. Update the Android client; the host protocol is unchanged.

Validation: the tagged release workflow checks the existing Android JVM tests, Release lint, native test-source compilation and signed packages. Physical-handset layout verification remains separate.
