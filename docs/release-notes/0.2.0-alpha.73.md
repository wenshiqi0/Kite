# Kite 0.2.0-alpha.73

Codex `send_message_to_user_async` calls now appear as normal assistant messages. Chat displays the message body with its original Markdown and line breaks instead of exposing the internal function name, arguments and `accepted` receipt.

The shared Rust presentation applies to live updates and existing offline history. Original calls, receipts and call IDs remain available internally for paging, reconnect and duplicate-event merging. Malformed payloads and failed delivery retain their diagnostic tool details; other tools and question forms keep their existing behavior.

This release builds on Alpha 72. Update the Android client to see the fix; no host update is required.

Validation: 70 local agent/FFI tests pass, including new coverage for pending/completed delivery, cached history, Markdown, duplicate events, calls and receipts split across pages, malformed arguments and native message conversion. Rust formatting and strict Clippy pass. Tagged CI additionally validates the complete Rust workspace, Android JVM tests/lint and the signed APK before publishing. Physical-phone confirmation remains separate.
