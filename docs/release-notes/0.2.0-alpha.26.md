# Kite 0.2.0-alpha.26

- Keep new-session entries and confirmation disabled until the preceding session operation completes, preserving the draft instead of accepting an action that the busy guard would ignore.
- Negotiate 10ms Opus packets for the MediaCodec path, batch decoder input/output work and avoid polling audio counters per packet. The Alpha 24 pipeline produced sound but failed the sustained-playback acceptance; Alpha 25 adds explicit throughput/drop thresholds after warmup.
- Play remote desktop system sound on Android using Opus decoding and AudioTrack. A persistent mute toggle is available in the workspace menu. Watch, Operate and PiP share the stream audio lifecycle; audio focus loss silences playback and disconnect releases resources.
- Keep the host audio device and local playback unchanged when connecting, avoiding the default-sink switch/restore path seen before the PulseAudio abort. This is a mitigation, not a patched upstream library.
- Treat a newly created session without a provider history file as waiting for records, rather than a sync failure. Preserve existing cached and locally pending messages.
- Keep startup terminal output out of Chat. Show a clear ready/preparing state, while retaining deliberate terminal and diagnostics access.
- Retry temporary chat initialization and historical gap reads without replaying prompts, answers, approvals or desktop input. Include bounded history failure details in diagnostics.
- Show actual desktop connection state. Idle and failure offer recovery actions; only real pending operations show a spinner. Bound discovery/handshake and stalled-video waits, and release input when SSH closes.

The matching Linux archive is built from the same source. Existing history, host profiles, device SSH identity, trust, pairing and clipboard preferences retain their formats. FFI bindings and library advance together; host API 1 / adapter protocol 5 remain unchanged.

Controlled validation covers new-session presentation and first-message/reconnect behavior separately from actual video and host interruption. Physical-phone Tailscale acceptance remains separate. The observed Sunshine/PulseAudio abort and audio-capture workaround are documented; this release does not claim a confirmed cause for every WAN disconnect.
