# Kite 0.2.0-alpha.33 — 签名兼容测试

针对手机报告的安装错误 `-103`，新增 **`-compat-v2.apk` 兼容包**。请优先下载这个文件覆盖安装。

兼容包使用原签名证书，启用 v1/v2、关闭 v3/v4；功能与本版本普通 APK 完全相同，保留 Alpha 32 的公开文本展示、重置卡次数和到期倒计时等功能。无需卸载现有应用。

CI 分别校验 API 23 的 v1、Android 16 的 v2、证书身份及 16 KiB 对齐，并要求两个 APK 的非签名内容完全一致。普通 APK 同时保留用于对照。

这是签名解析路径的兼容测试；是否解决手机的安装失败，需要真机安装结果确认。
