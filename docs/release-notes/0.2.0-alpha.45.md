# Kite 0.2.0-alpha.45

- 客户端包含完整的 DSH 新建会话入口、后端可用性驱动的选择列表、发送就绪判断和按能力显示的控件。
- 主机端同时保留 `harnessApi=1` 和既有会话生命周期接口，包括闲置回收、按需恢复及停止终端时不提交聊天输入的保护。
- 继续使用主机私有环境变量启用 DSH；未启用、模型鉴权失败或 SDK 握手失败时不在客户端展示。已有身份、信任、配对与外部服务保留。

Android 产品界面与 Alpha 43 相同；其原生选择/隐藏和初始化测试、真实 DSH 工具/记忆/重连检查继续适用。合并后的后端已通过 52 项测试，并由标记 CI 验证 Rust、Android、签名及同步主机包。运行中断时不自动重放模型请求或工具。

安装包验证和匹配主机部署结果记录在 [DSH 验收说明](../product/2026-11-02/dsh/acceptance.md)。主机配置详情按需阅读 [DSH 指南](../development/dsh.md)。
