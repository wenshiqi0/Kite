## Antigravity ACP 接入加固与原生 Skills 支持

- 修复 ACP 工具结果返回非对象 JSON `rawOutput` 时的解析报错，支持渲染 ACP `diff` 块并规范化多行工具标题。
- 支持 `session/list` 超出最近窗口时自动经 `session/load` 核实并恢复历史会话（真正缺失的会话仍拒绝新建空上下文），重启/关闭时优雅发送 `session/close`。
- 接入 `agy acp` 推送的原生 Skills 与斜杠命令（`available_commands_update` → `skills/list`），支持客户端技能选单与 `/skill` 原生调用。
- 同步显示 Antigravity 账号等级（`_meta.antigravity.tier` → `planType`），并优化非默认模型的思考强度标签与默认值。

验证记录：153 项 TypeScript/主机测试、全部 Rust `kite-herdr`/`kite-agent`/`kite-app` 测试与本机 `agy 1.5.16` 只读探活通过；正式安装包由 GitHub 标签 CI 构建、签名并校验。

建议同步更新 Linux 主机与客户端以获得完整体验。
