- Include partially visible growing replies when measuring distance from the latest message, and expose the jump action directly to accessibility.
- Keep **Back to latest** hidden for taps and small history drags. Show it after a meaningful scroll, with a separate near-tail threshold to prevent flicker. Reading and scrolling retain the complete conversation.
- Put real **plan allowance** in the model picker to the left of the message input. Show independent quota windows, remaining percentages, reset times and optional extra credits from the current Codex owner. Refresh independently of chat and distinguish unavailable or stale data.
- Make the message field compact, remove the floating model label, and leave space above the bottom safe area. Model and reasoning controls remain available beside the input.
- Add **Disconnect desktop** to the upper-right workspace menu. Stop the media session and release remote input while retaining SSH, chat and the agent session.

Host profiles, history, SSH identity/trust, pairing and clipboard preferences retain their formats. FFI bindings and the library are regenerated together. Host API 1 / adapter protocol 5 are unchanged; the synchronized Linux package retains the existing node identity and externally owned services. Claude plan allowance is not connected.
