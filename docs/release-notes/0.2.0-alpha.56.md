# Kite 0.2.0-alpha.56

Agent 内存预算按实际占用显示与判断，可回收缓存单独展示。

- 主机面板、预警、启动准入和修改上限统一扣除未映射的可回收文件缓存及内核缓存；tmpfs、常驻文件映射和尚待写回的数据仍计入用量。
- 调低上限前先回收缓存并核验余量；重申现有限额不会因缓存接近上限而误报保护失效。
- 保留不高于预算的内核硬上限，实际分配增长时回收缓存，超额且无法回收时仍触发限制。

本地验证：36 个 Bun 测试、71 个 Rust 应用测试、类型检查、lint、Clippy 和格式检查通过。隔离内核测试验证约 165 MiB 文件缓存不计入实际用量，安全回收缓存后将上限调低至 64 MiB，32 MiB 常驻分配正常，随后超额分配触发该隔离组的 OOM。Android 文案与公开发行包由本标签的可信 CI 构建验证；本次未重复物理手机交互或视频验收。
