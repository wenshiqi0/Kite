# Kite 0.2.0-alpha.42

- Skills 列表优先显示插件提供的友好名称与简短简介，避免把内部插件标识和长篇触发说明作为主要文案。
- 已选技能标签与无障碍提示同步使用友好名称；搜索支持展示名称、简介及原始标识。
- 缺少展示信息时回退到原有名称和说明；技能调用继续使用原始名称和路径。
- 更新共享 Rust 元数据与 Android UniFFI 绑定；保留现有签名身份，提供常规 APK、v2 兼容 APK 和同步 Linux 主机包。

Validation: 141 Rust tests and all-target Clippy, 70 Release JVM tests, Release lint and instrumentation compilation, a real Codex metadata-loader check with temporary fixtures, and three native API 36 skill-picker tests passed. The native checks use an isolated x86_64 harness; physical-phone installation and public ARM64 execution are separate acceptance.
