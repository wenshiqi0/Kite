# Kite 0.2.0-alpha.11

- Add automatic, bidirectional text clipboard sharing with one persistent **同步剪贴板** switch in settings. Once enabled, copy and paste normally while Kite is focused and the desktop is in Operate; Ctrl/Cmd+V waits for outgoing text. Remove manual transfer actions. Watch/background pauses sharing; this Alpha supports UTF-8 text up to 256 KiB and requires `xclip` on Linux X11.
- Add default hybrid input: direct canvas touch plus a movable floating mouse with a relative movement area, held left/right buttons and a continuous wheel. Support dragging with a held button and a second finger on the movement area or canvas. Keep relative pointer speed independent of video zoom and preserve source-pixel touch mapping.
- Fix session drawer dismissal with a close button, scrim and Back, while retaining disabled edge-open gestures. Block remote input under the drawer and release held buttons when leaving operation.
- Render Markdown emphasis in model-question choices/descriptions and approval explanations. Stabilize leading streaming bold text, preserve exact code/commands and original choice values, and retain raw Markdown when copying full replies.
- Allow adding another saved host without replacing existing hosts. Preserve device identity, SSH trust, pairing and conversation history; keep the Alpha 10 signing certificate and v1/v2/v3 verification.

Validation: 60 Rust tests, 10 host-adapter tests, 4 publisher tests, 13 Android JVM tests, 6 native API 36 tests, and controlled real Linux clipboard/mouse/zoom checks. Physical-phone responsiveness and WAN behavior still need device validation. See [interaction acceptance](https://github.com/wenshiqi0/Kite/blob/v0.2.0-alpha.11/docs/product/2026-10-30/hybrid-input/acceptance.md).

An isolated herdr-core 0.1.14 experiment resumed the same Codex thread and retained its history/context. It does not switch the production Herdr TUI service. macOS/Linux desktop nodes, multi-machine MCP and richer image/file/formula rendering remain subsequent implementation stages.
