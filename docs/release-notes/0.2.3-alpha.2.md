## Google Antigravity

Kite 的「新建会话」支持选择 Google Antigravity。可以聊天、发送图片、选择模型与思考强度、处理工具审批、取消请求并恢复原会话。

请配套升级客户端与主机节点。在主机安装 Antigravity CLI 后，运行 `agy acp --login` 登录 Google，再在主机配置的 `environment` 中启用 `KITE_ENABLE_ANTIGRAVITY=1`。[主机配置](https://github.com/wenshiqi0/Kite/blob/main/docs/backend-setup.md#google-antigravity)

Google 显示账号验证提醒时，请在 Google 页面完成验证。
