# Kite 0.2.6

- 支持 **Antigravity 套餐额度监控**：主机通过官方只读命令 `agy -p /usage --output-format json` 按需获取各模型分组（Gemini Models、Claude and GPT models、Gemini 4 Argon 等）的 5 小时与周周期剩余/已用比例及重置时间，不阻塞聊天轮次、不消耗模型额度。
- 客户端（Android、macOS、Windows）均展示 Antigravity 额度分组与当前模型摘要，同时显示剩余百分比与已用百分比，并支持手动刷新；macOS 聊天栏新增可点击额度详情弹窗。
- **Antigravity 默认开启 Turbo**：新建 Antigravity 会话默认使用 `tool_permission: turbo`（`--dangerously-skip-permissions`），仍可按会话切回主机默认权限并在冷启动恢复原选择。

验证：四端 PR CI（Android Release APK、macOS Client、Windows Client 含运行时检查、Docker Linux server）全部通过；140 项主机测试、114 项 `kite-agent`/`kite-herdr` 测试、134 项 `kite-app` 测试通过，并在本机真实 `agy 1.5.14` 上完成只读额度与默认 Turbo 验证。
