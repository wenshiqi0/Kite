# Alpha 85 — Inspect finished subagents

- The folded subagent header shows how many workers have completed, alongside any active workers.
- Tap a worker to view its recent public messages, tool details and final result in a read-only sheet. Refresh updates the same worker's records; the sheet shows when an older portion is outside the bounded history window.
- Branch arrows expand descendants independently of opening the worker's records. Viewing a worker keeps the parent conversation selected and submits no prompt or resume operation.
- Rust validates the selected host, parent conversation and descendant chain before using the existing provider-history reader.

This build also contains the work already merged into main: conversation-runtime and typed-message integration, Docker server packaging, and the first ACP prompt's live-status and persisted-history fixes.

Validation includes Rust scope/isolation tests, Android JVM tests, Release lint and native UI test-source compilation. The installed host's read-only history projection was checked against a real completed worker and includes its final result. Physical Android interaction remains separate from these checks.
