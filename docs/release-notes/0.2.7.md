# Kite 0.2.7

- 新增跨主机与跨供应商的异步会话控制。Agent 可创建会话、提交任务、查询或等待状态、读回有界结果，以及显式取消和释放。断线后可按会话与轮次继续观察。
- 派生会话保留父会话和任务标签。Android、macOS、Windows 增加关联任务、只读预览和接管入口。人工审批与提问进入 Kite 通知链路。
- 声明写入的会话受同目录写锁和父会话配额保护。Antigravity 的严格和人工审批远程轮次使用常规权限。
- 修复目录存在未知 provider 时网关整份目录读取失败的问题。更新执行主机和调用端的 Kite 后，独立运行的 `kite-acp.service` 在任务空闲时单独刷新。模型发起的新任务统一使用 `kite_session_*`，旧短任务入口保留给已有自动化。

在本机隔离环境验证了真实 Antigravity 模型的断线恢复、通知日志、原生协议审批、工具输出和多轮上下文。真实跨机模型联调及真机通知验收另行进行。
