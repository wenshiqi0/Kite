# Kite 0.2.0-alpha.23

- Send mouse movement and scrolling continuously through a fixed 16ms coalescing window. New movement no longer restarts a 200ms quiet timer. Clicks and key transitions flush earlier events in order; committed text keeps a fixed 200ms buffer.
- Keep 1080p/source resolution and the fullscreen mouse / split-view trackpad. Use a conservative initial 6Mbps video budget for Tailscale addresses, without reducing requested dimensions or FPS.
- Prefer hardware decoding, drain output before feeding input, retry transient decoder pressure without immediately discarding reference frames, and render the newest decoded output when behind.
- Move frame-render callbacks off the UI thread. Include bounded decoder FPS, queue/render latency and recovery counters in diagnostics.

Rust tests, focused input/performance JVM tests, Android compilation and Release lint pass. The controlled Alpha 22 local-emulator video baseline is recorded for comparison with this public package. Physical-phone Tailscale latency and bandwidth require live confirmation; a requested 60fps mode is not a measured 60fps guarantee.

Existing history, host profiles, device SSH identity, trust, pairing, clipboard preferences and host API 1 / adapter protocol 5 retain their formats. FFI bindings and library are generated together. The matching Linux package is built from the same commit.
