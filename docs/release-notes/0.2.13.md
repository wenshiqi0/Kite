## 全 Provider 全局系统提示词注入与统一异步提问表单

- **统一全局系统提示词与会话级 Kite MCP 注入（RFC 0035）**：为全部受管 Provider（Codex、Antigravity、Ply、DSH）在会话启动/恢复时自动追加 Kite 全局系统提示词，并挂载透传 `KITE_SESSION_ID` 的 `kite` 与 `kite_acp` 会话级 MCP（子任务派发、宿主/桌面操作与结构化提问均优先通过 Kite）。
- **Antigravity `ask_question` 接入统一交互表单（RFC 0036）**：宿主托管层实时将 `ask_question` / `Run ask_question` 投影为统一异步提问表单，提交回复时自动解包为清晰问答文本传回 `agy acp`，并在历史记录中完整恢复与清理待答状态。
- **三端多选表单支持**：Rust 核心/FFI 与 Android / macOS / Windows 客户端统一支持 `is_multi_select` / `multi_select` 复选框多选及自定义输入。

验证记录：159 项 TypeScript/主机测试、全部 Rust `kite-agent`/`kite-app`/`kite-ffi` 单元测试、严格 Clippy 与 PR/main 多平台 CI 均通过；正式安装包由 GitHub 标签 CI 构建、签名并校验。

建议同步更新 Linux 主机与客户端以获得完整体验。
