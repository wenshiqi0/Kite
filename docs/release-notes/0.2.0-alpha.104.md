Windows x64 客户端首次 Alpha 发布，源码已并入 `main`。

- 管理远程主机：添加、编辑、移除、连接与断开，支持独立多主机连接和自动恢复。
- 使用远程会话、流式聊天、模型与思考强度、权限设置、审批、提问、附件及 Skills。
- 观看和操作远程桌面，支持 H.264 视频、声音、全屏和可选文本剪贴板共享。
- Windows 本机仅承担客户端角色；本次 Release 只交付 Windows 包。

下载 `kite-0.2.0-alpha.104-windows-x64.zip`，完整解压后运行 `Kite/Kite.exe`。程序自带 .NET 运行时，无需另装 .NET。首次连接前，请把客户端设备公钥加入远程 Kite 主机，并核对 SSH 主机指纹。

安装包由 Linux 交叉编译，并在 Windows runner 检查设备密钥加密与持久化、主机增删改、H.264 解码和 WPF 启动渲染。随附逐文件摘要清单和 `SHA256SUMS-windows.txt`。

这是未签名的开发 Alpha。真实 Windows 设备与远程主机的端到端操作、IME、物理音频设备和公网质量仍需实机验收。Windows N 需要系统 Media Feature Pack 才能解码视频。
