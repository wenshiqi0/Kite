# Kite 0.2.0-alpha.12

- Host management opens as a separate panel of cards. Add a host, tap its card to edit, and save back to the list; connecting is explicit.
- Portrait split view places a collapsible trackpad below the desktop and above Chat. Its left / wheel / right row supports held-button movement, and closing it returns space to the conversation.
- Fullscreen uses a smaller draggable mouse icon and compact expanded controls. Zoomed desktops pan with one finger; tapping still clicks, while long press or a held mouse button drags remote objects through the same source-coordinate transform.
- The desktop keyboard opens the system IME directly. Composing text stays local; committed text batches for about 200 ms and flushes before keys, clicks and shortcuts.
- Codex history supports older/newer pages and return-to-latest. New output does not replace the reading window, and failed/empty reads preserve existing content. Continuous scrolling across page boundaries no longer opens a scroll-cancellation error. Long lists remain virtualized and message grouping ignores video-statistics-only changes.
- Existing hosts, recent history, device keys, SSH trust, Sunshine pairing and clipboard preferences are retained. The host adapter upgrades alongside the APK without restarting an existing Codex owner.

Android versionCode: **14**. ARM64; Android 8.0 or newer. Alpha prerelease.

Validation and product evidence are recorded in [native acceptance](https://github.com/wenshiqi0/Kite/blob/v0.2.0-alpha.12/docs/product/2026-10-31/compact-controls/acceptance.md). This release does not migrate production sessions to herdr-core or introduce macOS/Linux desktop clients. Physical-phone responsiveness and WAN conditions require user validation.
