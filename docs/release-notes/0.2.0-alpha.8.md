# Kite 0.2.0-alpha.8

- Render assistant replies and public progress as rich text: headings, emphasis, ordered and task lists, quotes, inline and fenced code, links, strikethrough and tables. Streaming replies resize as content arrives. Keep text selection and add a full-reply copy button, including table source.
- Fix a blank or tiny desktop on first entering split view. Measure and position the video Surface in the same layout pass instead of waiting for a divider drag. Keep one decoder while changing layout or split height.
- Preserve the 1920×1080 source desktop and the shared coordinates used for zoom and remote input. Viewing, operation and PiP retain their existing behavior.
- Keep message history, saved hosts, device identity, trust and pairing. This update changes Android presentation and requires no backend protocol migration.

Validation: Android lint and host unit tests; four native device tests for first-pass Surface geometry, zoom/PiP mapping, rich-text spans and streaming height, safe links, and an attached narrow table that settles without touch. Reproduced the old 1×1 Surface, then verified a visible desktop immediately after entering split on an API 36 ARM64 emulator. See `docs/product/2026-10-30/rich-text/acceptance.md` for scope and evidence. This is an Alpha prerelease.
