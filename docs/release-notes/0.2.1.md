# Kite 0.2.1

- 发布 0.2.1 正式版，提供 Android arm64 安装包、Linux x86_64 主机包与 Windows x64 原生客户端。
- 汇总已验证的聊天历史恢复、关联任务、图片相册与音视频附件改进；修复 Rust 工具输出被误识别为图片附件的问题。
- 删除已与后台分离的 Codex 会话时，保留复用该后台的其他会话和进程。
- Windows 客户端支持远程主机管理、聊天、审批与远程桌面，由 Linux 交叉构建后在 Windows CI 中验证身份持久化、H.264 解码和启动渲染。
- 正式交付统一通过 GitHub CI 构建并发布到 GitHub Release；版本、源码提交及各产物 SHA-256 均记录在发布清单中。本地测试继续由各开发环节处理。

请同步更新 Android 客户端和 Linux 主机。Android 可覆盖安装，保留原有设备身份与主机信任。Windows 请完整解压 ZIP 后运行 Kite/Kite.exe，并保留同目录的运行时和 DLL 文件。
