# Implementation stages — 2026-10-31

The user authorized staged implementation, retaining existing history, host trust, device identities and pairing. Desktop backend migration targets herdr-core evaluation first; no production Herdr TUI session is replaced before restoration is validated.

Delivery recorded here: [0.2.0-alpha.17](https://github.com/wenshiqi0/Kite/releases/tag/v0.2.0-alpha.17), Android versionCode **19**, with a matching Linux x86_64 host package. The [publication evidence](product/2026-10-31/anchored-input-and-linux-node/published-release.json) records passing main/tag CI, exact package hashes, in-place Android installation and the official Linux binary deployed on wen.linux. The arrow remains fixed to its controls through zoom/pan; a real 1.4s continuous gesture delivered no intermediate input and one final position after quiet. Phone chat traversed the node, and the same owned provider recalled its token after node update. Four profiles, identity/trust/pairing, catalogue and 14 complete cache files were retained. Full desktop remote-client UI, durable multi-machine message delivery and production herdr-core migration remain separate work.

1. **Android experience (Alpha 17 delivered):** complete independently synchronized conversations, per-session full caches and versioned message edits; local virtual rendering with one screen ahead / half a screen behind; no history network loading or data eviction on scroll. Fullscreen uses a control-relative arrow and an ordered 200ms quiet input window, tactile feedback and the right-hand rail; the trackpad is limited to portrait split view. Host cards show connection state and primary actions, with configuration and diagnostics available separately. A consistent dark palette covers Compose and native rich content. [Control/card acceptance](product/2026-10-31/compact-mouse-and-hosts/acceptance.md), [pointer correction](product/2026-10-31/virtual-pointer/acceptance.md), [complete-history acceptance](product/2026-10-31/complete-transcript/acceptance.md) and [RFC 0013](rfcs/0013-complete-transcript-and-dark-workspace.md). Alpha 12's prior [publication record](product/2026-10-31/compact-controls/published-release.json) remains historical. Direct system IME, source-resolution mapping, session questions/approvals and the one-switch text clipboard remain supported. Desktop audio and image/file clipboard formats are still pending.
2. **herdr-core migration experiment (restoration feasibility verified):** isolated herdr-core 0.1.14 reattached the same disposable Codex thread, displayed its old history, and the model recalled the previous token. A follow-up stopped the old owner and repeated restoration with a fresh provider process without legacy pane environment; JSON-RPC confirmed the original thread ID. [Recorded result](product/2026-10-30/herdr-core-migration.md). Production remains on Herdr TUI. Runtime-independent identity/routing, questions/approvals, automatic recovery and full archive/restore still need validation before a migration RFC is accepted.
3. **Linux desktop host (first stage delivered):** persistent Kite Node, native GTK host panel, private SSH/Unix bridge, matching adapter and user-service integration. Existing Herdr/Sunshine and provider identities are reused; GUI closure leaves them running. Official package installation, mobile owned chat/context recovery, binary/compressed transfer and MCP queries passed. [Linux guide](linux-desktop.md), [RFC 0014](rfcs/0014-linux-host-node.md) and [acceptance](product/2026-10-31/anchored-input-and-linux-node/acceptance.md). Full desktop remote-client UI and macOS host adapters remain pending.
4. **Multi-machine MCP (pending; host-local stdio queries available):** machine/session identity, explicit tool targets, durable work/messages/results and artifact references, local stdio integration and authenticated peer transport. MCP exposes the operations; task delivery, restoration and input ownership are application state.
5. **Rich content expansion (pending):** shared semantic message blocks with native renderers for prose, command/log/diff, images/files and citations; streaming partial markup; formulas/diagrams after baseline content coverage. Keep command text exact and do not execute model HTML.

Current facts: one active SSH connection is held by mobile AppCore; Linux Kite Node now owns the host bridge and local lifecycle policy. Capture discovery still uses Linux `/proc`. The host panel does not establish a full desktop remote client or durable multi-node orchestration. Upstream herdr-core and Herdr TUI are separate servers with no automatic shared agents. Sunshine's macOS host support is marked experimental upstream; screen capture/input must be validated on both target platforms.
