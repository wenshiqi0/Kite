# Unicode 键盘映射的消费时序

状态：实施中。

Alpha 63 的两次标签 CI 均在隔离 GTK/X11 目标的 512 个不同 Unicode 字符校验处失败。字符数量正确，内容哈希错误；证据显示有限键码池复用时，繁忙客户端仍按旧映射处理部分输入。产品先等待 50ms 让客户端消费 MappingNotify，再发键；此等待短于已声明覆盖的 200–250ms 目标调度间隔。

每批更新映射并 XSync 后，使用与映射保留阶段相同的 350ms 稳定窗口，再发出实际按键。保持每批后 350ms 保留窗口和条件恢复原映射。CLI/MCP、文本内容、键码选择、安全边界及不修改剪贴板的契约不变。稀有字符很多的长输入会增加耗时。

验收保持原来的严格内容哈希、映射恢复、CLI/MCP 和忙碌目标检查；在 Ubuntu 24 的隔离 Xvfb/GTK 上覆盖 200ms 和 250ms 调度间隔，并重跑可信标签 CI。不得跳过输入用例或放宽结果校验。
