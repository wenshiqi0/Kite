# RFC 0005：手机操作视口与会话入口

> 状态：已实现（Android Alpha 5） · 2026-10-29

用户在 NX769J 的反馈：连接和无会话状态不清楚、无法发消息、没有横屏入口，操作模式无法放大后精确点按。保留已经批准的设备密钥、主机和信任记录；同次生成 FFI，不增加旧入口。

- 产品模式统一称“只看 / 操作”；agent 暂停保持独立。两种模式都能本地缩放和移动视口，源桌面分辨率独立。
- Android 以源桌面像素作为唯一输入坐标系。视口保存比例、源中心点及缩放，渲染和直接触控使用同一变换及逆变换；相对鼠标移动也用该比例换算。信箱区不发送点击。
- 操作提供直接触控和触控板。触控板单指移动、轻点左键、双击后拖动、双指轻点右键、双指滑动滚动、捏合本地缩放；三指或显式“移动画面”用于平移视口。捏合不得同时触发远端滚动或右键。
- 全屏有明确横屏/竖屏按钮；进入全屏可主动请求横屏，不依赖用户打开系统自动旋转。只改变手机呈现，保留源分辨率和媒体会话。
- Rust 推送 SSH / herdr 连接阶段和 agent 的 launch_pending / interactive_ready（后者只表示托管启动就绪，不拦截普通会话）；Android 显示具体阶段、失败原因和空会话下一步。连接表单在实际成功前保持可见。
- 用户补充确认：连接主机后应直接聊天。连接阶段自动复用已有 agent，优先名为 `kite` 的后端会话；没有 agent 时，在主机用户目录创建 `Kite` 工作区并启动默认 Codex，SSH 断开不停止它。服务器的 agent 名称唯一性用于合并并发准备；未知写入结果只做读取核对，不自动重放启动。失败时提供“重试准备”，手动新建仅作可选入口。
- 可选的新建会话入口通过 herdr 0.9.5 的 workspace.create 和 agent.start 创建独立 pane，由用户选择 Codex / Claude 和项目目录；不自动向已有 shell 注入命令，不自动提交模型任务或安装全局 hook。启动结果未确认时保留 workspace 供核对，不自动重放。

验收覆盖视口逆映射、缩放焦点与边界、操作缩放后点击同一远端目标、触控板捏合不产生远端事件、系统自动旋转关闭时手动横屏、无 agent 可见引导、会话启动和真实 herdr prompt 路径。APK 仍由签名 Alpha CI 发布。

参考：网易 UU 远程官方手机教程 https://uuyc.163.com/help/20241203/40220_1197649.html 与观看模式 https://uuyc.163.com/help/viewonly.html，采用明确的操作面板和只看模式；具体手势按 Kite 的坐标映射和防误触要求实现，不声称复刻未验证的 UU 细节。
