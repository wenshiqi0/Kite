# RFC 0010：混合鼠标、剪贴板与聊天入口

> 状态：已采纳 · 2026-10-30

用户确认按阶段继续实现。Android 先修侧栏与基础 Markdown，再提供画面触控和仿真鼠标同时可用的操作界面，以及双向剪贴板。保留源分辨率、主机/信任/身份/历史；FFI 同次生成，不保留旧入口。操作模式不自动暂停 agent。

- 侧栏关闭时禁止边缘滑开，打开后允许点遮罩、关闭按钮、返回键和划回关闭。侧栏覆盖桌面时取消并阻止远端输入。
- 模型选项的标签与说明使用统一 Markdown 解析器展示强调和行内代码，点击行为仍是选择选项，提交原始值。代码和转义星号保持原文。正文、工具结果、审批的后续完整富文本改造需要保留内容语义与命令原文。
- 流式段落开头的未闭合加粗在展示时临时闭合，完成时使用真实原文；代码块、转义和复制内容不改变。审批分别提供解释、原始命令与工作目录，解释渲染 Markdown，命令保持等宽原文。
- 默认混合操作：画面使用源桌面像素的绝对定位；可移动/收起的鼠标控件提供相对移动区、独立左右键和连续滚轮。按住左右键可配合移动区或画面拖动；松开、取消、离开操作模式、后台和打开侧栏都释放按键。传统触控板与直接触控仍是可选输入方式。相对鼠标灵敏度与画面缩放分离，捏合、平移、滚动一旦识别锁定到本次手势结束。
- 用户进一步确认剪贴板需要无感同步，设置中只有一个开关。原生保存本机剪贴板授权偏好并在前台获得焦点、当前桌面处于操作模式时桥接系统剪贴板；Rust 经既有 SSH 执行同一主机的剪贴板读写、去重、方向判断和初始同步。复制不会自动键入或粘贴，Ctrl/Cmd+V 在发出前等待本机内容送达。只看、失焦、后台、切换主机暂停桥接。新命令带主机 ID，单次 UTF-8 上限 256 KiB，不记录内容。macOS 使用 pbcopy/pbpaste；Linux 绑定同用户 Sunshine 的 X11/Wayland 环境并使用 xclip/wl-clipboard。图片/文件 MIME 在节点服务阶段扩展。
- 验收包括三种侧栏关闭路径和禁用边缘打开、选项加粗及原始代码、左右键按住拖动、连续滚轮、缩放后绝对点击、混合输入释放、实际双向剪贴板及主机身份/大小/失败约束。

后续桌面节点先隔离评估 herdr-core 的同一 provider thread 恢复，确认迁移后再决定替换当前 herdr TUI，保持生产会话运行。
